# MySQL ITS Reviewer

A web-based reviewer for the ITS Database exam (USER SCHOOL).

## Features
- **175 questions** extracted from the actual exam PDF
- **136 questions** with answer keys
- Practice Mode (instant feedback per question)
- Exam Simulation Mode (review all at end)
- Browse & search all questions
- Score tracking, streaks, and results summary

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Import the repo in [vercel.com](https://vercel.com)
3. Deploy — no environment variables needed!

Or use Vercel CLI:
```bash
npm i -g vercel
vercel
```
